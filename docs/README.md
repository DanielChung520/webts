# 文檔目錄

本目錄包含專案相關的所有文檔：

- [API 文檔](./api.md) - 詳細的 API 接口說明
- [開發指南](./development.md) - 開發環境設置和規範
- [部署指南](./deployment.md) - 部署流程和注意事項

## 文檔更新指南

1. 所有文檔都使用 Markdown 格式編寫
2. 文檔更新後需要在對應文件的更新日誌中記錄變更
3. 重大更新需要通知所有團隊成員

### 同步流程

1. 每週五下班前進行文檔審查和同步
2. 使用專門的分支名稱格式：`docs/更新描述`
3. commit 信息格式：
   - 新增文檔：`docs: add 文檔名稱`
   - 更新文檔：`docs: update 文檔名稱`
   - 刪除文檔：`docs: remove 文檔名稱`
4. 重要更新需要在團隊群組通知

### 文檔審查清單
- [ ] 檢查文檔格式是否規範
- [ ] 確認文檔內容是否最新
- [ ] 檢查超連結是否有效
- [ ] 更新版本號和日期
- [ ] 添加更新日誌
